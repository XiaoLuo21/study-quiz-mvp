> 沈阳农业大学通识选修课《AI+OPC创业实践》· HW08（第5周）MVP 交付包

> **开源代码仓库（GitHub）**：https://github.com/XiaoLuo21/study-quiz-mvp  
> **设计风格**：V2 高级排版（暖纸白 + 森林绿 + 陶土橙，参考 Apple / Anthropic 官网的极简克制感）

## 一句话介绍

免费、轻量、无需注册的学习自测工具：**选择题库 → 即时判分与解析 → 结果报告 → 本轮错题重练**。数据保存在本地设备，保护用户隐私。

---

## 核心功能清单（P0 全部达成）

1. **三大主题题库**：大学英语六级、AI 通识素养、计算机基础，各 8 道题目，共 24 道精选题。
2. **免登录即测**：无需注册、无后端数据库、不索取个人隐私，打开网页即可立即作答。
3. **即时反馈与解析**：选项点击后立即锁定，答对绿色高亮，答错红色高亮并显示正确答案与知识点解析。
4. **成绩单与用时分析**：答完 8 题自动计算得分、正确数、需要复习数及作答总秒数。
5. **错题专项重练**：成绩页自动列出本轮做错的题目，支持一键针对错题二次练习；做对后分数实时更新，全对时自动禁用重练按钮形成闭环。
6. **本地数据持久化**：使用浏览器原生 `localStorage` 记录本设备累计答题场次与历史正确率，支持随时一键清除。
7. **全平台响应式与无障碍**：兼容 375px 手机端至 1280px+ 桌面端，无横向溢出；支持键盘数字键 `1–4` 作答、`Enter` 下一题，配备屏幕朗读无障碍 live region。

### 1. 公网访问（任何人可用）
直接点击访问：[https://xiaoluo21.github.io/study-quiz-mvp/](https://xiaoluo21.github.io/study-quiz-mvp/)

### 2. 本地直接使用
- 双击直接打开 `index.html`，或在当前目录运行：
  ```bash
  python -m http.server 8000
  ```
- 浏览器打开 `http://localhost:8000/` 即可开始离线练习。
