# 知测 QuizLab｜6 小时课程 MVP Agent 交付包

> 现有文件已包含**可以在浏览器中使用的前端网页**。用户/Agent 不需要先搭建前端项目脚手架。

## 一句话

免费的知识测验小网站：**选择题库 → 即时判分与解析 → 结果报告 → 本轮错题重练**。

## 开始使用

- 直接双击 `index.html`，或者在本目录运行：`python -m http.server 8000`。
- 浏览器打开 `http://localhost:8000/`，可进行完整练习。
- 三个题库：英语六级 / AI 通识 / 计算机基础，各 8 道，共 24 题。
- 本地累计数据存浏览器 `localStorage`，不含注册、后端和任何外部网络请求。

直接发出以下指令，无需继续拆分需求：

## GitHub Pages（Agent 执行阶段）

1. 在已有授权账号创建公开仓库，如 `study-quiz-mvp`。
2. 推送本目录文件到 `main` 根目录，确保 `index.html` 在根目录。
3. 仓库 `Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save`。
4. 发布完成后用独立浏览器访问 GitHub Pages 网址，验证真实可用后记录链接。不要编造已发布 URL。
